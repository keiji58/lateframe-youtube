# LateFrame

[English](README.md) | **日本語**

YouTube の**映像だけ**を遅延させ、無線 / Bluetooth ヘッドホンによる音の遅れに口パクを合わせる Chrome 拡張機能です。

## なぜ

Bluetooth ヘッドホンでは音が少し遅れることがあります。YouTube は映像と音声が一体なので、再生位置をずらすと両方動いてしまいます。LateFrame は音声はそのままにし、古い映像フレームを表示します。

## インストール（開発用 / パッケージ化なし）

1. `chrome://extensions` を開く
2. **デベロッパーモード**をオンにする
3. **パッケージ化されていない拡張機能を読み込む**で、このリポジトリのフォルダ（`manifest.json` がある場所）を選ぶ
4. すでに開いていた YouTube タブは再読み込みする

Chrome ウェブストアへの公開は、手元で試すために必須ではありません。

## 使い方

1. 無線ヘッドホンを接続して YouTube を再生する
2. ツールバーの LateFrame アイコンからポップアップを開く
3. **有効**をオンにする
4. **映像遅延**を 0 から上げ、口の動きと音が一致する値を探す  
   プリセット（0 / 100 / 200 / 300 ms）で大まかに合わせてから微調整してもよい

**0 ms** のときは処理を行わず、通常の YouTube 表示のままです。

## 仕組み

1. 元の `<video>` は再生し続け（音声はそのまま）、遅延中は画素を隠す
2. 可能なら `requestVideoFrameCallback` でフレームをバッファする
3. Canvas オーバーレイに、音声より N ミリ秒古いフレームを描画する

## 権限

| 権限 | 用途 |
|------|------|
| `storage` | 有効状態と遅延量の保存 |
| `https://www.youtube.com/*` | YouTube 視聴ページでの動作 |

アカウント連携・解析・拡張独自のネットワーク通信はありません。

## 既知の限界

| 項目 | 内容 |
|------|------|
| 字幕 | YouTube 字幕は別 DOM のため、映像と一緒には遅延しません |
| CPU / メモリ | 高解像度・高フレームレートほど負荷が増えます |
| ライブ配信 | バッファが安定しにくく、同期がぶれやすい場合があります |
| ミニプレイヤー / PiP | 通常の視聴画面を優先しています |
| 広告 | 広告再生中は遅延を一時停止します |
| 対象サイト | YouTube のみ（`https://www.youtube.com/*`） |

## うまくいかないとき

1. **遅延が 0 ms のまま** — スライダーを上げてください（0 では何もしません）
2. **入れたのに効かない** — インストール / 更新後、YouTube タブを一度再読み込みしてください
3. **直後だけ普通に見える** — 約 0.3〜0.5 秒のウォームアップ後、`LateFrame: +Nms` が出れば動作中です
4. **差が分かりにくい** — まず 200〜300 ms で試し、その後微調整してください

確認方法: ページ DOM で `.late-frame-overlay` を探す。オーバーレイがありステータスに遅延が表示されていれば Canvas 経路は動いています。
